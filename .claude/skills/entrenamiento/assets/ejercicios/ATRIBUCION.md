# Atribución de las ilustraciones de ejercicios

- **Ilustraciones (`img/*.svg`):** Everkinetic, proyecto de datos abiertos basado en everkinetic.com, creado por Greg Priday. Repositorio: https://github.com/everkinetic/data. Licencia: Creative Commons Atribución-CompartirIgual 4.0 (CC BY-SA 4.0), https://creativecommons.org/licenses/by-sa/4.0/deed.es.
- Cada ejercicio tiene dos archivos: `<clave>-1.svg` (fase «relaxation» del original) y `<clave>-2.svg` (fase «tension»). Se copiaron sin modificar; solo cambió el nombre del archivo. El origen exacto de cada uno está en `img/registro.json`.
- **Datos del catálogo (`catalogo.json`):** nombres, equipo, músculos y claves de técnica, en español; son de elaboración propia. Solo se reutiliza la ilustración de Everkinetic.
- **Mapas musculares:** los dibuja `scripts/musculos.py` (esquema propio).

El PDF del plan añade una página de créditos con esta atribución.
